# NASA Moon surface assets

The Earth Moon surface render uses the NASA Scientific Visualization Studio CGI Moon Kit
natural-color global map derived from Lunar Reconnaissance Orbiter (LRO) Camera data.

- Albedo: `moon_lroc_2k.jpg` — NASA SVS CGI Moon Kit, `lroc_color_2k.jpg`.
- Height reference: `moon_height_1024.jpg` — NASA SVS CGI Moon Kit, `ldem_3_8bit.jpg`,
  derived from LRO/LOLA elevation data.

NASA source: https://svs.gsfc.nasa.gov/4720/
Credits: NASA Scientific Visualization Studio; Ernie Wright (USRA); Noah Petro (NASA/GSFC);
LRO/LROC and LOLA instrument teams.
